# Пиксельный админ

Пиксельный платформер-квест по программам системного администратора. Сделан как игровая оболочка к учебной лаборатории: каждая комната — одна программа из статьи [«Программы системного администратора»](https://serveradmin.ru/programmyi-sistemnogo-administratora/).

## Как играть

Открой `index.html` в браузере — или играй по ссылке GitHub Pages.

| Клавиши | Действие |
|---|---|
| `←` `→` / `A` `D` | идти |
| `Space` | прыжок |
| `↑` `↓` / `W` `S` | лестница |
| `E` | открыть терминал |

В каждой комнате нужно добраться до терминала, ввести правильную команду и дойти до двери. Прогресс хранится в `localStorage`.

## Запуск настоящих программ

В окне программы есть кнопка «Запустить настоящую программу» — она открывает установленное приложение через ссылку `sysadminlab://`. Браузер при первом клике спросит разрешение.

Работает это на каждой машине отдельно: обработчик ссылки прописывается в реестр один раз.

```powershell
# из папки с игрой, один раз
powershell -ExecutionPolicy Bypass -File install-handler.ps1
```

Скрипт скачивает `launcher.ps1` в `%LOCALAPPDATA%\PixelAdmin` и регистрирует протокол в `HKCU\Software\Classes\sysadminlab` — без прав администратора. Отключить:

```powershell
Remove-Item HKCU:\Software\Classes\sysadminlab -Recurse
```

Поддерживаются: mRemoteNG, KeePassXC, VS Code, Joplin, draw.io, RustDesk, Aspia. Если программа не найдена, лаунчер откроет папку с дистрибутивами.

## Комнаты

1. mRemoteNG — подключения (`ssh srv-billing`)
2. KeePassXC — хранилище паролей (`kdbx`)
3. VS Code — запуск скрипта (`powershell -File hello.ps1`)
4. draw.io — схема сети (`.drawio`)
5. Joplin — база знаний (`markdown`)
6. RustDesk — удалённая помощь (`id`)
7. Aspia — инвентаризация (`Get-PhysicalDisk`)
8. PowerShell — автоматизация (`Get-PSDrive`)
9. Открытие смены — регламент (`питание`)
10. Финал — включение по сети (`wake-on-lan`)

## Технически

Один файл, без зависимостей и сборки: HTML5 Canvas, тайловая карта генерируется детерминированно по номеру уровня, физика AABB, пиксельная графика рисуется кодом — внешних ассетов нет.
